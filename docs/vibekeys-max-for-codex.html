Questions

Which AI coding tools does it work with? +

VibeKeys is tool-agnostic — Claude Code, Codex, Cursor, Gemini CLI, OpenCode, Copilot and more. This release adds one-command profiles for the two most common (vibekeys profile codex / claude) so switching between them is instant.

Does switching profiles change my other keys? +

No. The codex and claude profiles touch only CUSTOM and YOLO. Every other key keeps its existing binding, so switching never surprises you.

How do I switch back to Claude Code? +

Run vibekeys profile claude. It restores CUSTOM to /compact + Enter and YOLO to Shift+Tab — a clean round-trip from the Codex profile.

It's 3D-printed — is the build quality good? +

Made-to-order 3D printing is what enables multiple colors and custom key icons. Build quality is the thing early customers compliment most. Every order includes a 30-day exchange for any manufacturing defect or shipping damage.

Is the software open source? +

Yes — the vibekeys CLI that drives the device is open source under GPL-3.0, so your control surface is fully inspectable and scriptable.
