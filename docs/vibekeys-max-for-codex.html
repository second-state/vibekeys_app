Questions

What is VibeKeys MAX? +

It's a physical Bluetooth keyboard controller for AI coding assistants. The vibekeys CLI talks to it over BLE to set key bindings, push status to its screen, and more. This release adds first-class support for OpenAI Codex alongside Claude Code.

Does switching profiles change my other keys? +

No. The codex and claude profiles touch only CUSTOM and YOLO. Every other key keeps its existing binding, so switching never surprises you.

How do I switch back to Claude Code? +

Run vibekeys profile claude. It restores CUSTOM to /compact + Enter and YOLO to Shift+Tab — a clean round-trip from the Codex profile.

What does the confirmation look like? +

After every binding is applied you get one line — ✨ You're with Codex now — both in your terminal and on the keyboard's display. If a binding fails to send, you see the error instead.

Is it open source? +

Yes. VibeKeys is released under the GNU General Public License v3.0 (GPL-3.0). The source and full command reference live on GitHub.
